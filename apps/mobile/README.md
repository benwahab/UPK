# Application Android

Livraison prévue au sprint 3. Expo / React Native, avec les mêmes paquets
`@upk/domain`, `@upk/i18n` et `@upk/ui` que le web.

Contraintes : Android 8 minimum, APK/AAB signé, mode hors ligne en lecture,
recherche et fiche lieu disponibles sans réseau après première ouverture.
