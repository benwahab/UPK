# Application Android

Emplacement réservé. La v1.0 est livrée en **PWA installable** depuis
`apps/web` ; le sprint 3 durcit cette PWA pour Android 2 Go / 3G (ADR-008).

navigateurs et preuve d'un besoin natif. Si elle est prise, l'app réutilisera
`@upk/domain`, `@upk/i18n` et `@upk/ui`, avec Android 8 minimum, APK/AAB
signé et fiches consultables hors ligne après première ouverture.
